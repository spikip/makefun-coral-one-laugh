## About this entry

The best one-liners take something ordinary and let it behave like
something else entirely, so this entry gives the smart fridge a jealous
partner's voice. The appliance does not beep an error code or suggest a
filter change; it writes a breakup letter, which is already funny before
the twist arrives. The twist is the affair itself: the narrator has been
seeing the takeout place behind the fridge's back for six months, which
turns a kitchen gadget into the wronged party and the human into the one
caught cheating. It lands on a first read because the setup and the
punchline share a single sentence, and the whole line stays well inside
the two hundred character cap. The program holds the line, checks it
against that cap, and writes it to /output/entry.txt exactly as the
bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line joke to `/output/entry.txt`.
